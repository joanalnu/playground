# Vector Calculator

The goal of this sub-dir project is to create a `C++` script that computes typical numerical vector operations (scalar, vector product, ...) with the aim to remember and put into practice using the `vector` library in `C++`.

Often, the first coding project, is to create a calculator to do basic arithmetic calculations (+, -, *, /) with input and output (`cin`, `cout`) commands. Here I modified that to be vector operations to comply with the goal.
